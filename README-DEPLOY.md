# نشر الموقع (العزل المتقدم) — تعليمات

الموقع جاهز بالكامل وتم اختباره تلقائياً بنجاح (تشغيل المتصفح على الجوال/الحاسوب،
التنقل، قوائم الجوال، ألوان وتباين النصوص، بدون جافا سكريبت، ووضع تقليل الحركة).

## ما الذي تحتاجه منك لنشر الموقع على الإنترنت

نشر الموقع يتطلب حساباً على Vercel (مجاني) وتسجيل الدخول — وهي خطوة لا يمكن تنفيذها
بشكل تلقائي لأنها تحتاج مصادقة بشرية (متصفح / بريد إلكتروني).

### الطريقة أ (الأسهل): تسجيل الدخول عبر المتصفح
1. افتح أي واجهة أوامر (PowerShell) واكتب:
   `powershell -ExecutionPolicy Bypass -File "C:\Users\EES\Desktop\المشروع رقم 1\website\deploy.ps1"`
   سيفتح المتصفح صفحة Vercel للمصادقة — سجل الدخول بحساب Google أو GitHub أو بريد إلكتروني.
2. بعد تسجيل الدخول، شغّل الأمر نفسه مرة أخرى وسيُرفع الموقع مباشرة وستظهر لك
   الرابط (مثال: `https://celaz-insulation.vercel.app`).

### الطريقة ب: رمز Token (توريد بيئة)
1. من موقع Vercel → Settings → Tokens → Create Token.
2. ثم: `& "C:\Users\EES\AppData\Local\nodejs-portable\node-v24.19.0-win-x64\node.exe" ... ` أو أسهل:
   عيّن المتغير `VERCEL_TOKEN` ثم شغّل `deploy.ps1`.

## بعد نشر الموقع (أمر مهم)
عدّل النطاق في الملفات (بالأمر التالي) ليصير الرابط الفعلي مقبولاً لمحركات البحث:

`powershell -ExecutionPolicy Bypass -File "C:\Users\EES\Desktop\المشروع رقم 1\website\swap-domain.ps1" <your-deployed-url>`
مثال:
`... swap-domain.ps1 celaz.mul.vercel.app`

هذا يحدّث canonical + Open Graph + JSON-LD + robots + sitemap دفعة واحدة.

### نطاق مخصص (اختياري، بتكلفة سنوية ~10-12 دولار)
- سِجّل نطاقاً مثل `celaz-mutakaddem.com` لدى Namecheap أو Cloudflare Registrar ثم
  اضبطه على المشروع في Vercel (Project → Domains) وأضف سجلات DNS CNAME.
- لا حاجة لتغييرات نوعية لأن الملفات تستخدم النطاق القديم أصلاً.

## تحقق أخير لإدارة محركات البحث (بعد النشر)
- Google Search Console: أضف الموقع وأرسل sitemap.xml للفهرسة.
- ملاحظة: رقم الواتساب الحالي في الموقع هو `01554671424` — إذا تغيّر رقم الشركة، استبدله في كل مكان
  (index.html و js/main.js) بذات الصيغة الدولية `20` بدل `015`.

## أدوات داخل المجلد
- deploy.ps1 — نشر مباشر عبر Vercel CLI (مثبّت محلياً، لا يحتاج إدارة).
- swap-domain.ps1 — تبديل النطاق في الملفات دفعة واحدة.
- index.html / css / js — الموقع كامل؛ عدّل النص والأرقام بحرية ثم أعد النشر بـ deploy.ps1.
- manifest.webmanifest — بيانات تثبيت الموقع على الجوال؛ لا يحتوي نطاقاً فلا يحتاج تحديثاً عند تبديل النطاق.
- أجزاء الموقع: قسم رئيسي، إحصائيات، عن الشركة، الخدمات، خطوات العمل، لماذا نحن، آراء العملاء، مناطق التغطية (مدن المملكة)، الأسئلة الشائعة، وقسم تواصل نهائي (اتصال / واتساب / بريد) مع زر واتساب عائم — لا يوجد نموذج إرسال.

— تم الإعداد على جهازك: Node.js محمول (v24.19.0) و Vercel CLI (58.7.1).
